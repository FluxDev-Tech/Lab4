# Student Portal - John Lawrence V. Martinez
CS106 Lab Exercise 4. Node.js + Express + EJS + Bootstrap 5.

## Run
1. Install Node.js (v18 or newer)
2. Open a terminal in this folder
3. `npm install`
4. `node app.js`
5. Open http://localhost:3000

Pages: `/` Home, `/services` Services, `/about` About.
Bootstrap and icons load from a CDN, so you need an internet connection.
Test sizes: F12 > Toggle Device Toolbar > 375, 768, 1366 px.
